## Payouts APIs

### Payout APIs

- [Overview](https://www.cashfree.com/docs/api-reference/payouts/overview.md): Explore the Cashfree Payouts APIs that disburse funds to bank accounts, UPI IDs, and cards with sandbox endpoints, authentication, and webhooks.
- [Getting Started](https://www.cashfree.com/docs/api-reference/payouts/getting-started-with-payouts-apis.md): Review the prerequisites, sandbox credentials, IP whitelisting, and signature setup you need before testing Cashfree Payouts APIs in your integration.

#### Account

- [Get Balance](https://www.cashfree.com/docs/api-reference/payouts/v1/get-balance.md): Use this API to get the ledger balance and available balance of your account. Available balance is ledger balance minus the sum of all pending transfers (transfers triggered and processing or pending now).
- [Internal Transfer](https://www.cashfree.com/docs/api-reference/payouts/v1/internal-transfer.md): Use this API to request an internal transfer at Cashfree. The internal transfer API is useful for multiple Payouts accounts. The API response will either result in an ERROR or SUCCESS response.
- [Self Withdrawal](https://www.cashfree.com/docs/api-reference/payouts/v1/self-withdrawal.md): Use this API to request a self withdrawal at Cashfree. Self withdrawal is allowed a maximum of 3 times a day. The API response will either result in an ERROR or SUCCESS response. The status of the withdrawal request is available on the dashboard.
- [Get Balance V1.2](https://www.cashfree.com/docs/api-reference/payouts/v1/get-balance-v12.md): Use this API to get the ledger balance and available balance of your account. Available balance is ledger balance minus the sum of all pending transfers (transfers triggered and processing or pending now).
- [Internal Transfer V1.2](https://www.cashfree.com/docs/api-reference/payouts/v1/internal-transfer-v12.md): Use this API to request an internal transfer. It is useful for accounts with multiple fund sources. You need to provide either the rechargeAccount or paymentInstrumentId and toPaymentInstrumentId along with the amount.

#### Authentication

- [Authorize](https://www.cashfree.com/docs/api-reference/payouts/v1/authorize.md): Use this API to authenticate with the Cashfree system and obtain the authorization bearer token. All other API calls must have this token as Authorization header in the format 'Bearer <token>' (without quotes) for them to get processed.
- [Verify](https://www.cashfree.com/docs/api-reference/payouts/v1/verify-1.md): Verify the bearer token generated. If the token does not exist, is invalid, or has expired, the response "Token is not valid" is returned. Regenerate token in case of token expiry for making API calls ( use /payout/v1/authorize for this).

- [Standard Transfer V2](https://www.cashfree.com/docs/api-reference/payouts/v2/transfers-v2/standard-transfer-v2.md): Use this API to initiate an amount transfer at Cashfree Payments. It is an async request by default.
- [Get Batch Transfer Status V2](https://www.cashfree.com/docs/api-reference/payouts/v2/transfers-v2/get-batch-transfer-status-v2.md): Use this API to get the status of the initiated batch transfer. You can use either the batch_transfer_id or cf_batch_transfer_id to fetch the details.

#### Beneficiary V2

- [Get Beneficiary V2](https://www.cashfree.com/docs/api-reference/payouts/v2/beneficiary-v2/get-beneficiary-v2.md): Use this API to get the details of a particular beneficiary from your account. #### Verify and Pay

- [Validate Payout](https://www.cashfree.com/docs/api-reference/payouts/v2/validate-payout-v2.md): Validates a UPI VPA or phone number and returns a single-use transfer token valid for one hour. Pass this token to the [Process Validated Payout API](/docs/api-reference/payouts/v2/verify-and-pay-transfers-v2) (`POST /payout/transfers`) to initiate the payout.
- [Process Validated Payout](https://www.cashfree.com/docs/api-reference/payouts/v2/verify-and-pay-transfers-v2.md): Initiates a UPI payout using the transfer token returned by the [Validate Payout API](/docs/api-reference/payouts/v2/validate-payout-v2). The token is single-use and expires after one hour. When you use a transfer token, only `upi` is supported as the transfer mode.
